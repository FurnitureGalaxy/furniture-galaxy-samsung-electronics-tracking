FURNITURE GALAXY — SAMSUNG ORDER TRACKING ONLINE v1

This is the Samsung version of the existing LG online ETA page.

DISPLAY ORDER
1. Excel Column E — PO NUMBER
2. Excel Column M — MODEL NUMBER
3. Excel Column K — QUANTITY ORDERED
4. Excel Column S — ESTIMATED SHIP DATE — PLEASE ADD 10 DAYS TO THIS

IMPORTANT
The webpage displays the date from Column S as supplied. It does NOT automatically add 10 days.

UPDATING THE WEBSITE
Open "Upload New Samsung Order Tracking Excel" on the webpage.
Choose the newest Samsung orderTracking .xlsx file.
Click "Upload & Replace Data".
The website immediately replaces the old data and updates the Last Updated time.

DEPLOYMENT
The included render.yaml and requirements.txt follow the same online deployment structure as the LG version.
For persistent uploaded data on Render, use the persistent disk/data setup used by the LG deployment.
